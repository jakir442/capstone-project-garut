## 📌 About the Project

**Kopilogi Modern Coffee Shop Website** adalah proyek capstone yang dikembangkan oleh mahasiswa Teknik Informatika, Institut Teknologi Garut (ITG), dalam program **Dicoding Asah 2026**.

Proyek ini bertujuan mengembangkan website resmi Kopilogi sebagai pusat informasi bisnis, media promosi digital, dan sarana untuk membantu pelanggan menemukan menu, lokasi, serta kanal pemesanan yang tersedia.

Pengembangan website didasarkan pada hasil wawancara dengan **Kak Galfin selaku Store Manager Kopilogi**. Kebutuhan sistem dan ruang lingkup pengembangan ditentukan berdasarkan kondisi bisnis serta informasi yang diperoleh selama proses discovery.

Website ini tidak dimaksudkan untuk menggantikan sistem operasional internal Kopilogi, melainkan melengkapi kehadiran digital bisnis melalui pengalaman pengguna yang modern, informatif, responsive, accessible, dan mudah digunakan.

### Project Approach

**Discover → Define → Design → Develop → Test → Deliver**

## 🏪 About Kopilogi

Kopilogi merupakan bisnis Food & Beverage (F&B) yang memulai perjalanan pada tahun **2015** sebagai angkringan sederhana di depan rumah.

Seiring berkembangnya usaha, Kopilogi kemudian berpindah ke Food Market Sehati sebelum akhirnya berkembang menjadi coffee shop dan menetap di lokasi Cikuray sekitar tahun **2017**.

Berdasarkan hasil wawancara, Kopilogi menyediakan berbagai produk F&B, antara lain:

- Coffee
- Non-coffee beverages
- Food
- Dessert
- Pastry
- Croissant
- Produk F&B lainnya

Kopilogi melayani pelanggan secara langsung di lokasi dan memanfaatkan platform pihak ketiga untuk pemesanan online.

Bisnis ini juga telah menggunakan sistem digital internal, termasuk POS untuk transaksi kasir dan spreadsheet untuk pendataan.

Berdasarkan hasil wawancara, Kopilogi telah memiliki sistem digital untuk mendukung beberapa aktivitas operasional dan menggunakan kanal pihak ketiga untuk pemesanan online.

# 🔐 Authentication & Authorization

Area admin menggunakan authentication berbasis NextAuth.

Role utama:

```text
customer
admin
super_admin
```

Konsep authorization:

- `customer` — akses sebagai pengguna publik.
- `admin` — mengelola data berdasarkan cabang yang diberikan.
- `super_admin` — memiliki akses administratif yang lebih luas.

Data administratif tidak boleh diakses atau dimodifikasi hanya berdasarkan informasi dari client.

Authorization harus tetap dilakukan di server.

```bash

```

```bash

```

Install dependencies:

```bash
npm install
```

---

## Environment Variables

Buat file:

```text
.env.local
```

Contoh konfigurasi:

```env
MONGODB_URI=your_mongodb_connection_string

AUTH_SECRET=your_auth_secret

CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

Nama environment variable harus mengikuti konfigurasi aktual yang digunakan project.

Jangan menggunakan credential production di repository.
